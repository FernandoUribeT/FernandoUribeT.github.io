Rules this demo enforces

  • A trip cannot be scheduled in the past. The attempt is rejected and the reason is explained.
  • Dragging uses Pointer Events, so it works the same with a mouse and with a finger on mobile.
  • The target cell turns green or red before you drop: the user knows the outcome before making the mistake.
  • Every action is narrated, rejections included. A silent rejection is worse than an explained one.
  • An individual color wins over the type color. If you recolor a type and some event has its own color, the demo says so instead of silently overwriting it.
  • Text color is computed from the relative luminance formula in WCAG, so it stays readable on whatever background you pick.
  • Everything is stored in localStorage: reload the page and your colors are still there.
  • The three filters combine, they do not add up: client and unit and driver. The counter always says how many events are visible out of how many exist.
Written from scratch in JavaScript, no libraries, no dependencies. The original module persists these colors and filters per user in the database.
